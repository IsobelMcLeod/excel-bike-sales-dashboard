Excel Bike Sales Dashboard

## Project Overview
This project presents an interactive Excel dashboard analysing bike purchase behaviour across different demographic and lifestyle factors.

## Dataset
The dataset contains customer-level information including:
- Gender
- Age bracket
- Income
- Education level
- Marital status
- Commute distance
- Bike purchase status

## Dashboard Features
- Average income by gender and purchase status
- Customer age bracket comparison
- Commute distance vs bike purchases
- Interactive slicers for:
  - Region
  - Education
  - Income
  - Gender
  - Purchase status

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard design and formatting

## Key Insights
- Middle-aged customers show the highest bike purchase rates
- Short to medium commute distances are associated with higher purchase likelihood
- Income and education level influence purchasing behaviour
